## ✨ Features

- 🎯 **Real-time ELO** for 1v1 and Team Games.
- 👻 **Click-Through:** Fully transparent, won't interfere with your gameplay.
- 📐 **Customizable:** Freely move and resize the window.
- ⚡ **Lightweight:** Optimized for zero performance impact.

## 🚀 Quick Start

1. Download the latest `.exe` from [Releases](../../releases).
2. Install and launch the app.
3. Enter your **Profile ID**.
4. Play! The overlay will automatically detect your match.

> 💡 **Tip:** Use **Edit Mode** to position the overlay and set your ID. Exit Edit Mode to make it click-through.
